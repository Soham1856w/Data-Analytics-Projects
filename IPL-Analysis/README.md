# 🏏 IPL Data Analysis Project

This project is based on IPL ball-by-ball data and focuses on analyzing team and player performances using Python. The dataset is explored to extract meaningful insights related to batting, bowling, and overall team performance.

The main objective is to understand cricket statistics through data analysis and visualization.

---

## 📊 Analysis Includes
- Total runs scored by each team  
- Top batsmen based on runs  
- Top bowlers based on wickets  
- Most sixes and fours by teams  
- Dismissal patterns  
- Extras analysis  
- Team-wise performance comparison  

---

## 🛠️ Tools Used
- Python  
- Pandas  
- Matplotlib  
- Seaborn  
- Numpy
- Jupyter Notebook
---

## 📂 Dataset
IPL ball-by-ball dataset (deliveries.csv) containing detailed match-level data such as runs, wickets, batsman, bowler, and extras.

---

## 📈 Key Outcome
The analysis helps in understanding:
- Which teams are strongest in batting and bowling  
- Which players perform consistently  
- How teams compare in different aspects of the game
