# Netflix Data Analysis

## Project Overview
Performed exploratory data analysis on Netflix dataset using Python.

## Tools Used
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Insights
- Netflix contains more Movies than TV Shows
- USA produces the highest Netflix content
- Content releases increased rapidly after 2015
- TV-MA is the most common rating category

## Visualizations
- Movies vs TV Shows
- Top Countries
- Release Trend
- Ratings Distribution
- Movie Duration Analysis
