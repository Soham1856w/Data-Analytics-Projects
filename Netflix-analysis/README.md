# 📊 Netflix Data Analysis

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on Netflix Movies and TV Shows dataset using Python libraries.

The analysis focuses on:
- Content distribution
- Release trends
- Ratings analysis
- Genre analysis
- Movie duration trends

---

## 🛠 Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📂 Dataset
Netflix Movies and TV Shows Dataset from Kaggle.

---

## 📈 Key Insights
- Netflix contains significantly more Movies than TV Shows
- USA dominates Netflix content production
- Content releases increased rapidly after 2015
- TV-MA is the most common rating category
- Most movies are around 80–120 minutes long
